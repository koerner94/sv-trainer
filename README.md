# SV-Trainer

Lern- und Pruefungstrainer fuer Immobiliensachverstaendige. Zwei fruehere Apps sind hier
zusammengefuehrt:

- **Pruefungstrainer** - Katalog Sachkunde und Bautechnik, frueher `app-pgatx482`
- **Rechenwege** - die vier Rechenwege der ImmoWertV, frueher `immowertv-hoerbuch/rechnen`

Beide alten Adressen leiten hierher weiter und bringen den bisherigen Lernstand einmalig mit.

Die App laeuft ohne Netz und speichert nichts ausser dem eigenen Lernstand im Browser des
Geraets. Es wird nichts hochgeladen und nichts gemessen.

Dieses Verzeichnis wird von einem Skript erzeugt.
